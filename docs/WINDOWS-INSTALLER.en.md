# Windows offline EXE installer

Document ID: HWI4U-WINDOWS-INSTALLER · Version: 1 · 2026-10-21

Download the Windows x64 setup EXE from the linked tested build/release, double-click it, accept the displayed license and select Install. HWI4U installs for the current user without administrator rights. Python3.14.8, Qt/PySide6-Essentials6.11.2 and shiboken6 are bundled. No separate Python, pip, terminal commands or internet connection are needed on the target PC. The build itself needs internet access. This0.21.1 installer is a TEST candidate until its actual Windows checks and user review pass; do not infer success from a workflow file.

Open Start → HWI4U0.21.1 → HWI4U, or HWI4U TEST. First launch shows the inventory-folder wizard, then creates an empty inventory and independent TEST dataset, running the full test gate; this can take several minutes. The proposed data directory is %LOCALAPPDATA%/HWI4U. If that path exists but initialization is incomplete, it is left unchanged: choose New inventory to get a different timestamped path, or Open existing inventory for a completed managed workspace. The chosen path is saved separately in %LOCALAPPDATA%/HWI4U-launcher.json; advanced --workspace overrides do not replace that setting. Diagnostics are written beside the selected data directory as <folder>-startup.log. Do not delete the earlier failed installation to retry.

Program files live in %LOCALAPPDATA%/Programs/HWI4U/0.21.1, separate from data. Existing completed inventories retain their production/TEST selections; ordinary shortcuts do not synchronize source, refresh TEST or promote code. Use the separate Prepare update in TEST shortcut deliberately to publish this installed version to TEST with full validation, then review TEST before explicit managed production acceptance. No TEST records are copied back. A local source-repository deployment does not update another Windows PC automatically.

Uninstall through Windows Installed apps or the versioned Start-menu Uninstall shortcut. Close that program normally first. Uninstall deletes only installer-manifest files and its own shortcuts/registration; it does not remove inventory folders, backups, attachments, launcher preferences, failed installations or unknown files. It does not alter PATH, file associations, global Python or HKLM. Old program versions are retained side by side. Keep independent full backups; same-disk copies are not independent backup protection.

This initial build is unsigned and not an MSI. Windows may show an unknown-publisher/SmartScreen prompt; do not disable Windows security. Compare the supplied SHA256SUMS.txt and review the verified download source. Code signing needs a separate certificate/account decision. Target is Windows11 x64; automated installation qualification uses Windows2025 x64, not the user's physical PC. No Windows ARM/x86/macOS/mobile installer is claimed here.

Build: use Python3.14.8 x64 on Windows, install requirements.txt and FOSS NSIS3.13, then run python tools/build_windows_installer.py --output dist/windows-installer --makensis "C:/Program Files (x86)/NSIS/makensis.exe". The output must be new. The allowlisted source, full relocatable CPython standard library and pinned binary Essentials/shiboken wheels are copied; no private inventory, venv, system settings or runtime snapshots are included. The builder verifies runtime prefix/module paths and emits a complete SHA256 installation manifest. NSIS generates the per-user EXE and exact-file uninstaller.

Validation: tools/windows_installer_smoke.py installs the real EXE into a disposable Unicode path, verifies installed hashes, removes development Python from PATH, runs the complete bundled suite, performs fresh initialization through the full gate, opens the native TEST client using the installed pythonw launcher and closes normally, then runs the real uninstaller. It checks that fictional inventory, partial-install diagnostics and an unknown program-directory file survive. No tests are skipped or constraints relaxed. CI artifacts include logs/receipt/manifest/checksum and expire after14 days; retained release assets and user-PC review are separate.

Dependency notices: HWI4U MIT and CPython LICENSE are included; PySide6-Essentials/shiboken wheel notices and dynamic Qt libraries remain replaceable. The bundle omits unnecessary Qt Addons. Unmodified upstream sources and license information: https://www.python.org/downloads/source/ , https://code.qt.io/cgit/pyside/pyside-setup.git/?h=v6.11.2 , https://download.qt.io/official_releases/qt/6.11/6.11.2/submodules/ , https://doc.qt.io/qtforpython-6/licenses.html . NSIS is a FOSS build tool: https://nsis.sourceforge.io/License . Windows and any compiler runtime retain their own platform terms; they are compatibility requirements of the requested Windows target.
