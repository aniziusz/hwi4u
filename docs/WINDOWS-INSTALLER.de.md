# Windows-Offline-EXE-Installer

Document ID: HWI4U-WINDOWS-INSTALLER · Version: 1 · 2026-10-21

Windows-x64-Setup-EXE aus dem verknüpften geprüften Build/Release herunterladen, doppelklicken, angezeigte Lizenz bestätigen und Installieren wählen. Installation nur für den aktuellen Benutzer ohne Administratorrechte. Python3.14.8, Qt/PySide6-Essentials6.11.2 und shiboken6 sind enthalten. Auf dem Ziel-PC sind keine separate Python-/pip-Einrichtung, Terminalbefehle oder Internetverbindung nötig. Der Build benötigt Internet. Dieser0.21.1-Installer ist bis tatsächlicher Windows-Prüfung und Benutzerabnahme ein TEST-Kandidat; Workflow-Datei allein belegt keinen Erfolg.

Start → HWI4U0.21.1 → HWI4U oder HWI4U TEST öffnen. Erster Start zeigt Datenordner-Assistenten, erstellt leeres Inventar mit unabhängigem TEST-Datensatz und vollständiger Testprüfung; das kann einige Minuten dauern. Vorschlag: %LOCALAPPDATA%/HWI4U. Existiert dort eine unvollständige Einrichtung, bleibt sie unverändert: Neues Inventar wählt einen anderen Pfad mit Zeitstempel, Vorhandenes Inventar öffnen einen vollständig verwalteten Arbeitsbereich. Auswahl steht separat in %LOCALAPPDATA%/HWI4U-launcher.json; --workspace überschreibt diese Einstellung nicht. Diagnose: <Ordner>-startup.log neben dem Datenordner. Frühere fehlgeschlagene Installation zum Wiederholen nicht löschen.

Programme: %LOCALAPPDATA%/Programs/HWI4U/0.21.1, getrennt von Daten. Vorhandene vollständige Inventare behalten Produktiv-/TEST-Auswahl. Normale Verknüpfungen synchronisieren keine Quellen, erneuern TEST nicht und geben keinen Code produktiv frei. Separate Verknüpfung Update in TEST vorbereiten veröffentlicht diese Version nach vollständiger Prüfung bewusst in TEST; danach TEST prüfen und ausdrücklich produktiv freigeben. Keine TEST-Datenrückkopie. Lokale Quellbereitstellung aktualisiert keinen anderen Windows-PC automatisch.

Deinstallation über Installierte Apps oder versionsbezogene Startmenü-Verknüpfung. Programm vorher normal schließen. Nur Dateien des Installationsmanifests, eigene Verknüpfungen/Registrierung werden entfernt; Inventare, Sicherungen, Anhänge, Startpräferenzen, Fehlerinstallationen und unbekannte Dateien bleiben. Keine Änderung an PATH, Dateizuordnungen, globalem Python oder HKLM. Alte Versionen bleiben nebeneinander. Unabhängige Vollsicherungen behalten; Kopien auf gleichem Datenträger sind nicht unabhängig.

Erste Version unsigniert und kein MSI. Windows kann Unbekannter Herausgeber/SmartScreen anzeigen; Sicherheit nicht deaktivieren. SHA256SUMS.txt und geprüfte Downloadquelle vergleichen. Signierung benötigt separate Zertifikat-/Kontenentscheidung. Ziel Windows11 x64; automatische Installerprüfung auf Windows2025 x64 ersetzt keinen Benutzer-PC-Test. Kein ARM/x86/macOS/Mobilinstaller zugesagt.

Build unter Windows mit Python3.14.8 x64, requirements.txt und FOSS NSIS3.13: python tools/build_windows_installer.py --output dist/windows-installer --makensis "C:/Program Files (x86)/NSIS/makensis.exe". Ausgabeordner muss neu sein. Nur freigegebene Quellen, vollständige verschiebbare CPython-Standardbibliothek und festgelegte Essentials-/shiboken-Wheels werden kopiert; keine Inventare, venv, Systemeinstellungen oder Laufzeitschnappschüsse. Laufzeitpräfix/Modulpfade werden geprüft, vollständiges SHA256-Manifest erzeugt. NSIS erstellt Benutzer-EXE und dateigenauen Deinstaller.

Prüfung: tools/windows_installer_smoke.py installiert echte EXE in isolierten Unicode-Pfad, prüft Hashes, entfernt Entwicklungs-Python aus PATH, führt gesamte gebündelte Testsuite sowie neue Initialisierung mit Vollprüfung aus, öffnet natives TEST per installiertem pythonw und schließt normal. Echte Deinstallation wird geprüft; fiktive Daten, Fehlerdiagnose und unbekannte Programmdatei müssen bleiben. Keine Tests übersprungen oder DB-Regeln abgeschwächt. CI-Artefakte enthalten Protokolle/Beleg/Manifest/Prüfsumme und verfallen nach14 Tagen; dauerhafte Release-Dateien und Benutzerabnahme separat.

Lizenzen: HWI4U MIT, CPython LICENSE und Hinweise der Essentials-/shiboken-Wheels bleiben enthalten; dynamische Qt-Bibliotheken austauschbar. Nicht benötigte Qt-Addons entfallen.
