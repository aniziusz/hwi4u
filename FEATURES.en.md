# Roadmap

Document ID: HWI4U-FEATURES · Version: 3 · 2026-10-18

Available in source 0.15.0/schema 22: local validated device entry; UUID/short labels; physical inventory, purchase/lifecycle/condition; assemblies via CLI; types/groups; software/firmware; network identity; sourced port connections; immutable evidence library; external photo/manual files; three-language UI; guarded scrolling; searchable list filters; optional text location; isolated TEST/production release workflow. Repository setup adds separate private-workspace initialization and source-only collaboration checks.

Planned, not implemented: qualified Windows support, Android/iOS entry, shared online/offline synchronization, graphical network topology, selected device metadata export with OPNsense/Home Assistant/KeePass profiles. APIs, target versions, mapping/conflicts and permissions require a separate implementation design. A roadmap is not a support claim or acceptance of any production release.
